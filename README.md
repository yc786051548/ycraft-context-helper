# YCraft 右键助手

把常用工具整合到 Windows 右键菜单，UI 与动效工具分组选择。

## 下载与教程

**[打开官网](https://ycraft-context-helper.pages.dev/)** · **[下载联网安装器（28.5 KB）](https://github.com/yc786051548/ycraft-context-helper/releases/download/v2026.10.26.2/YCraft-RightClick-Online.exe)** · [版本说明与校验文件](https://github.com/yc786051548/ycraft-context-helper/releases/tag/v2026.10.26.2)

[UI 使用指南](https://ycraft-context-helper.pages.dev/guide-ui.html) · [动效使用指南](https://ycraft-context-helper.pages.dev/guide-motion.html)

下载 EXE 后双击运行，勾选需要的工具即可。

- 自动识别 Windows 10 / Windows 11，并选择适配的右键菜单版本。
- 只下载勾选的工具；缺少 .NET 8 桌面运行库时再下载。
- UI 与动效分组，群晖网盘上传工具位于 UI 分组。
- 下载完成后验证 SHA-256，校验通过的缓存可复用。

支持 Windows x64，Windows 10 需 19044 或以上。已在 Windows 11 x64 实测 UI 工具安装，并通过脚本验证资源打包和文件夹创建；Windows 10 尚未进行真机安装验证，当前保留预发布标记。GitHub 下载速度取决于所在网络。
