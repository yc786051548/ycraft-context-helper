# YCraft 右键助手

把常用工具整合到 Windows 右键菜单，UI 与动效工具分组选择。

## 下载

**[下载联网安装器（约 29 KB）](https://github.com/yc786051548/ycraft-context-helper/releases/download/v2026.10.26.1/YCraft-RightClick-Online.exe)** · [查看版本说明与附件](https://github.com/yc786051548/ycraft-context-helper/releases/tag/v2026.10.26.1)

下载 EXE 后双击运行，勾选需要的工具即可。无需手动下载 ZIP 分包。

- 自动识别 Windows 10 / Windows 11，并选择适配的右键菜单版本。
- 只下载勾选的工具；缺少 .NET 8 桌面运行库时再下载。
- UI 与动效分组，群晖网盘上传工具位于 UI 分组。
- 下载完成后验证 SHA-256，校验通过的缓存可复用。

支持 Windows x64，Windows 10 需 19044 或以上。本版为预发布，仍需真实 Win10 / Win11 安装验收。GitHub 下载速度取决于所在网络。

本仓库用于分发安装包与分包。发布页中的 ZIP 附件由安装器自动使用；请勿手动改名或删除已发布的分包。
